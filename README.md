# Jack's Fast Break

A first-person lacrosse shooting game that runs in the browser. You've broken away with a free shot on goal. Move in, aim, and beat the goalie before the defender catches you.

## Play
Open `index.html` in any browser, or enable GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root).

## Controls
- **Phone:** joystick to move, drag or tap the field to aim, hold **Shoot** to wind up and release to fire
- **Desktop:** WASD / arrows to move, mouse to aim, hold click or Space to wind up and release to fire

## Rules
- 10 breaks per game; the goalie gets quicker every 3 goals
- More power = harder to save, less accurate
- Aim at the turf for a bounce shot
- Shoot before the defender catches you
